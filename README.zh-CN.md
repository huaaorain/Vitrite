**Vitrite** 是一个小巧的 Windows 工具，内置自动换行 TXT 阅读器，也可以通过全局快捷键手动调整任意窗口的透明度，并支持将窗口设置为“总在最前”（置顶）。

> [!NOTE]
> **重制项目说明**: 本项目是 Ryan VanMiddlesworth 原作（约 2002 年）的现代化 Fork 版本。针对 Windows 10 和 11 进行了原生重写，提升了安全性和稳定性。

## ✨ 现代化特性

此版本已根据现代 Windows 标准进行了全面重写：

*   **📖 内置 TXT 阅读器**: 直接打开小说文本，窗口变窄或变宽时会自动重新折行，不会再把长行截断在右侧。
*   **📚 可迁移书架目录**: 拖入或批量导入 TXT，作者和收藏状态保存在书库自身，书库目录可以随意更换。
*   **⭐ 特别喜欢与筛选**: 每本书右上角可点亮五角星，并按全部、特别喜欢、未特别喜欢三种状态筛选。
*   **🔎 拼音与作者目录**: 支持按书名拼音排列，或按作者分类并筛选同一作者的全部书籍。
*   **📦 便携书库**: 一键把 EXE、全部书籍、作者和收藏配置打成 ZIP；另一台电脑解压后直接运行。
*   **🪟 圆角界面**: Windows 11 使用系统原生圆角，Windows 10 使用圆角窗口区域。
*   **🔤 中文编码兼容**: 自动识别 UTF-8、UTF-8 BOM、UTF-16 LE/BE；无 BOM 的旧文本会按系统编码读取。
*   **🪟 阅读体验**: 支持字号调整、纯白或透明阅读背景、窗口透明度选择、滚轮阅读以及复制文本。
*   **📌 窗口置顶开关**: 阅读器和书架右上角都有图钉按钮，可随时切换是否固定在其他窗口上方。
*   **📊 响应式阅读信息**: 书名、字数和当前阅读进度分列显示，拖动窗口时自动重排，不再遮挡内容。
*   **🔅 低透明度阅读**: 阅读器不透明度最低可调至 10%。
*   **🎨 原生自绘界面**: 统一白色界面，命令栏按文件、字号、显示工具分组，并带悬停、按压和键盘焦点反馈。
*   **🌓 高对比度支持**: 阅读器适配 Windows 高对比度系统色。
*   **🪟 白色/透明底色**: 阅读器可切换纯白底色或透明底色；透明模式会取样背景明暗并自动选择黑色或白色文字。
*   **🔄 透明度状态同步**: 无论通过下拉菜单还是全局快捷键调整透明度，阅读器菜单都会显示当前实际透明度。
*   **🎛️ Ctrl+滚轮透明度**: 阅读器支持 `Ctrl+鼠标滚轮` 以 10% 步进调整透明度。
*   **🖱️ 透明模式可交互**: 透明底色不再穿透鼠标；阅读、选择、右键和滚轮都可正常操作，并提高了滚轮滚动速度。
*   **🔗 单实例打开**: 程序已运行时，再双击另一个 TXT 会在现有阅读器中直接打开。
*   **🛡️ 更安全的实现**: 移除了传统的 DLL 注入和全局键盘钩子，改用标准的 `RegisterHotKey`。这不仅更稳定，而且不会触发反病毒软件的误报。
*   **👁️ 高 DPI 支持**: 完整的 Per-Monitor V2 DPI 感知。在 4K 屏幕和多显示器混排环境下，UI 显示依然清晰锐利。
*   **🛡️ 崩溃恢复**: 若 Windows 资源管理器崩溃或重启，托盘图标会自动恢复。
*   **🌓 深色模式支持**: “关于”对话框会尝试适配系统的深色模式（Windows 10/11）。
*   **🌐 国际化支持**: 内置英文、简体中文和日语资源，根据系统 UI 语言自动切换。
*   **🛠️ 64 位支持**: 包含针对 x86 和 x64 架构的 Release 构建配置。

## ⌨️ 快捷键

### 阅读器

| 快捷键 | 功能 |
| :--- | :--- |
| **Ctrl + O** | 打开 TXT 文件 |
| **Ctrl + B** | 打开书架目录 |
| **Ctrl + 加号** | 增大字体 |
| **Ctrl + 减号** | 减小字体 |
| **Ctrl + 鼠标滚轮** | 以 10% 步进调整透明度 |
| **Ctrl + Shift + 1..9 / 0** | 调整阅读器透明度 / 恢复不透明 |

### 任意窗口透明度

| 快捷键 | 功能 |
| :--- | :--- |
| **Ctrl + Shift + 1..9** | 设置透明度级别 (1 = 10%, 9 = 90%, 0 = 重置) |
| **Ctrl + Shift + 0** | 将窗口重置为完全不透明 (移除透明效果)* |
| **Ctrl + Shift + +** | 切换 **总在最前** (使用主键盘区的 `+` 键) |
| **Ctrl + Shift + Num+** | 切换 **总在最前** (使用小键盘区的 `+` 键) |

*\*注意：为了安全起见，重置功能仅对本次运行中被 Vitrite 修改过的窗口生效。*

## 📖 使用方法

1.  直接运行 `Vitrite.exe` 会打开书架目录；也可双击通知区域的 Vitrite 图标。
2.  将 TXT 拖入书架，或点击“导入 TXT”。每次导入会提示填写作者，之后可右键卡片修改。
3.  点击卡片打开阅读器；点击卡片右上角五角星切换特别喜欢状态。
4.  使用“排序”选择书名拼音或作者分类，使用“筛选”和“作者”组合查询书籍。
5.  点击阅读器或书架右上角图钉，可切换窗口是否固定在最前。
6.  点击“设置书库...”更换书库目录；书库中的 `library.ini` 保存作者、收藏及书籍清单。
7.  点击“导出便携包...”生成 ZIP。另一台电脑解压后直接运行其中的 `Vitrite.exe`，会自动加载同目录 `library` 书库。
8.  关闭阅读器或书架不会退出后台透明度工具；开机自启时程序保持静默。

阅读器的详细 UI 规范见 [docs/ui-redesign.md](docs/ui-redesign.md)。

## 🏗️ 构建指南

**环境要求**: Visual Studio 2022 (Community 或更高版本)，需安装 C++ 桌面开发工作负载。

1.  打开 `src\Vitrite.sln`。
2.  选择目标架构（推荐 `x64`）。
3.  生成解决方案。

可执行文件将输出到 `x64\Release` (或 `Release`) 目录。
